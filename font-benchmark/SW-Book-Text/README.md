# SW Book Text — Benchmark Prototype

Original Hebrew book-text serif (Regular + Bold) with Latin, digits and punctuation, generated
entirely from Python construction scripts. **Prototype only**: no production licence is assigned,
nothing here is added to any SeferWorks catalog, and no claim of legal independence or copyright
protection is made (legal review required).

## Layout

| Path | Content |
|---|---|
| `fonts/SWBookText-Regular.ttf`, `fonts/SWBookText-Bold.ttf` | installable TrueType fonts (172 glyphs each) |
| `sources/SWBookText-*.ufo` | generated UFO3 sources incl. `features.fea` (editable in any UFO editor; regenerated by the build) |
| `src/swbook/` | the real "master": `geom.py` (pen/stroke kit), `hebrew.py`, `latin.py`, `misc.py` (digits, punctuation, marks), `kern.py` (optical kerning), `build.py` (UFO + FEA + TTF) |
| `specimen/SWBookText-Specimen.pdf` | 6-page A4 print specimen; `specimen/build_specimen.py`, `pdflib.py` (HarfBuzz layout + PDF writer), `texts.py` (shared text) |
| `tests/` | pytest suites `test_font.py` (52 tests incl. 2 weights), `test_pdf.py` |
| `tools/run_all.sh` | full pipeline + validators, writes `reports/test_results.txt` |
| `reports/` | `glyph_coverage.json`, `provenance_glyphs.json`, `provenance_summary.json`, `PROVENANCE.md`, `KNOWN_DEFECTS.md`, `WORK_STATUS.md`, `test_results.txt` |

## Build (exact)

```bash
cd font-benchmark/SW-Book-Text
pip install -r requirements.txt            # + poppler-utils for pdffonts/pdftotext
(cd src && python3 -m swbook.build)        # -> sources/*.ufo, fonts/*.ttf, reports/provenance_glyphs.json
python3 specimen/build_specimen.py         # -> specimen/SWBookText-Specimen.pdf
python3 tools/make_reports.py              # -> reports/glyph_coverage.json, provenance_summary.json
python3 -m pytest tests -v                 # automated tests
./tools/run_all.sh                         # all of the above + FontBakery + OTS, logged
```

Builds are deterministic (fixed timestamps, no randomness); `tests` rebuild twice and compare SHA-256.

## Design summary

* Hebrew: horizontal-stress serif. Horizontals are thick, verticals thin, produced by an *elliptical
  pen* (`geom.stroke`): the centre-line is stroked with a Skia stroker in an x-scaled space and
  scaled back, so contrast is identical across all letters. Roofs have a chiselled left terminal,
  free stems a flared foot. Regular pen 80/50 units (H/V), Bold 108/94.
* Latin: vertical-stress serif, slab-like unbracketed serifs, same pen idea (84/30 and 118/42).
* Metrics: UPM 1000, Hebrew letter height 650, lamed 800, finals −230; Latin x-height 440, cap 650.
  Digits are tabular, lining, height matched to Hebrew.
* OpenType: GPOS `mark` (mark-to-base: below, dagesh/inside, holam, shin dot, sin dot, rafe; extra anchors for
  descender finals and wide hataf marks), GPOS `kern` (script-generated optical pairs), GDEF classes.
* The shaped specimen uses HarfBuzz for all positioning; bidi is a documented UAX#9 subset (`pdflib.bidi_levels`).

See `reports/KNOWN_DEFECTS.md` and `reports/WORK_STATUS.md` for honest limitations.
